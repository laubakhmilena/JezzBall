# JezzBall

Адаптивная браузерная игра в духе JezzBall для публикации на Яндекс Играх.

Игрок проводит линии, отсекает безопасные области поля и старается захватить нужный процент пространства, не задев шары и опасные преграды. В игре есть 100 уровней, главы, магазин, бустеры, скины шаров, сундуки, достижения, внутриигровые монеты, rewarded-реклама, sticky-баннеры и расходуемые IAP через SDK Яндекс Игр.

## Что сделано

- 100 уровней с постепенным усложнением, разными скоростями шаров и типами преград.
- Адаптивный интерфейс для desktop, mobile и landscape-разрешений.
- Магазин с бустерами, жизнями, скинами, сундуками и IAP-пакетами.
- Умная витрина жизней: нельзя купить пакет, который частично сгорит из-за лимита.
- Случайные покупные сундуки с одной компактной плашкой результата.
- Система достижений с наградами монетами и сортировкой доступных наград наверх.
- Скины шаров из PNG-ассетов с fallback-отрисовкой на canvas.
- Интеграция с Яндекс Игры SDK: загрузка, сохранения, GameplayAPI, fullscreen/rewarded/sticky-реклама, покупки и обработка pending-покупок.
- Защита от повторного начисления IAP через сохранение обработанных purchase token.
- Блокировка выделения, drag, long tap и контекстного меню во время игры.

## Структура проекта

```text
JezzBall/
├── index.html
├── script.js
├── style.css
└── objects/
    ├── fone/
    └── game-objects/
```

Проект intentionally простой: без сборщика, без npm-зависимостей и без внешних ассетов. Для запуска достаточно открыть `index.html` через локальный сервер. На платформе Яндекс Игр SDK подключается через `/sdk.js`.

## Публикация на Яндекс Играх

Для отправки нужно архивировать содержимое папки проекта так, чтобы `index.html` лежал в корне архива.

В архив должны попасть:

- `index.html`
- `script.js`
- `style.css`
- `objects/`
- `README.md` можно оставить в репозитории, но для минимального игрового архива он не обязателен.

Не нужно добавлять старые скриншоты, zip-архивы, служебные папки или файлы с русскими именами. Текущие игровые пути не содержат пробелов и русских символов, а размер проекта меньше лимита Яндекс Игр 100 MB.

## Управление

- Мышь или палец: провести линию по полю.
- Кнопки ориентации: выбрать направление линии.
- Бустеры на панели уровня помогают ускорить линию, замедлить шары, защитить линию или снизить цель.

## Монетизация

- Rewarded video используется только по кнопке игрока: жизнь, случайный бустер или повтор после провала.
- Fullscreen-реклама показывается только в логических паузах: завершение уровней, рестарт, выход из уровня.
- Sticky-баннер показывается на спокойных экранах и в модалках магазина/достижений.
- IAP-покупки расходуемые, награды начисляются через SDK и консумируются после сохранения прогресса.

## Проверки перед публикацией

```bash
node --check script.js
```

Также стоит вручную проверить:

- запуск игры без ошибок консоли;
- уровни, магазин, достижения и сундуки;
- rewarded/fullscreen/sticky-рекламу через SDK;
- IAP-каталог, покупку, pending purchases и consume;
- адаптивность на `390x844`, `360x640`, `800x450`, `800x600`, `1280x720`.

## Автор

Проект сделан как игровая работа для портфолио: самостоятельная HTML/CSS/JavaScript-игра с адаптивным интерфейсом, прогрессией уровней и интеграцией требований Яндекс Игр.
