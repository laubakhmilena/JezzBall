# JezzBall

Браузерная аркадная игра, в которой игроку необходимо разделять игровое поле линиями, избегать движущихся шаров и постепенно захватывать свободное пространство.

Игра работает прямо в браузере и написана без игровых движков и сторонних JavaScript-фреймворков.

## Описание игры

**JezzBall** — это аркадная головоломка на реакцию и стратегическое мышление.

По игровому полю перемещаются шары. Игрок проводит вертикальные и горизонтальные линии, которые разделяют игровую область на части. Если в отделённой области нет шаров, эта область считается захваченной.

Для прохождения уровня необходимо захватить указанный процент игрового поля.

Во время построения линия уязвима. Если шар столкнётся с незавершённой линией, игрок получит штраф. После достижения максимального количества штрафов попытка завершается поражением.

## Основная цель

Для завершения уровня необходимо:

1. Запустить уровень на карте главы.
2. Проводить линии по игровому полю.
3. Не допускать столкновения шаров со строящейся линией.
4. Захватить требуемый процент пространства.
5. Получить звёзды, монеты и другие награды.
6. Открывать следующие уровни и главы.

## Игровая механика

Игровое поле содержит один или несколько движущихся шаров.

После действия игрока начинается построение линии. Линия растёт в двух направлениях до тех пор, пока не достигнет:

* границы игрового поля;
* уже захваченной области;
* существующей линии;
* препятствия.

После завершения линии поле разделяется на несколько областей. Область, в которой нет шаров, становится захваченной.

Процент захваченного пространства отображается в интерфейсе уровня.

### Победа

Игрок побеждает, когда процент захваченной территории достигает цели уровня.

Пример:

```text
Цель: 70%
Захвачено: 72%
Результат: уровень пройден
```

### Поражение

Игрок получает штраф, если шар сталкивается с линией до завершения её построения.

Попытка завершается поражением после достижения максимального количества штрафов.

## Управление

### Компьютер

Основное управление выполняется мышью.

* Нажатие на игровое поле создаёт линию.
* Направление линии определяется игровым управлением.
* Кнопка возврата открывает экран главы.
* Кнопка перезапуска начинает уровень заново.
* Кнопки усилений активируют доступные бустеры.

Также элементы интерфейса можно выбирать с клавиатуры с помощью клавиш `Tab`, `Enter` и `Space`.

### Мобильные устройства

На смартфонах и планшетах управление выполняется касаниями и жестами.

Интерфейс автоматически перестраивается в зависимости от:

* размера экрана;
* портретной или альбомной ориентации;
* доступной высоты;
* наличия сенсорного управления;
* безопасных областей экрана устройства.

## Система звёзд

За прохождение уровня игрок получает от одной до трёх звёзд.

Количество звёзд зависит от качества прохождения уровня, включая количество полученных штрафов.

Звёзды используются для:

* оценки результата прохождения;
* открытия наград главы;
* выполнения достижений;
* общего прогресса игрока.

Максимально можно получить:

```text
100 уровней × 3 звезды = 300 звёзд
```

## Игровые ресурсы

### Жизни

Жизни используются для запуска игровых уровней.

Максимальное стандартное количество жизней:

Потраченные жизни постепенно восстанавливаются. Оставшееся время отображается рядом со счётчиком жизней.

Жизни также можно получить:

* в качестве награды;
* из сундуков;
* в магазине;
* за просмотр рекламы;
* из специальных наборов.

### Монеты

Монеты можно получить:

* за прохождение уровней;
* за получение звёзд;
* из сундуков;
* за выполнение достижений;
* из наград глав;
* за рекламные награды;

Монеты используются для покупки:

* усилений;

## Усиления

В игре предусмотрено пять видов усилений.

### Линия

```text
fastLine
```

Следующая линия строится быстрее.

### Пауза

```text
slowBalls
```

Временно уменьшает скорость движения шаров.

### Щит

```text
lineShield
```

Защищает строящуюся линию от одного столкновения с шаром.

### Фокус

```text
targetEase
```

Уменьшает требуемый процент захвата в текущей попытке.

### Откат

```text
penaltyRepair
```

Убирает один полученный штраф в текущей попытке.

## Препятствия

На уровнях могут находиться препятствия разных типов.

### Безопасные препятствия

Безопасные препятствия влияют на геометрию уровня, но не уничтожают строящуюся линию.

### Опасные препятствия

Столкновение строящейся линии с опасным препятствием может привести к штрафу или разрушению линии.

### Движущиеся препятствия

Некоторые препятствия перемещаются по заданной траектории и усложняют выбор безопасного места для построения линии.

## Главы и уровни

Игра содержит:

```text
10 глав

10 уровней в каждой главе
```

Каждая глава имеет:

* собственное визуальное оформление;
* отдельную карту уровней;
* набор наград;
* прогресс по звёздам;
* сундук главы;
* постепенное увеличение сложности.

Сложность может повышаться за счёт:

* увеличения количества шаров;
* увеличения скорости шаров;
* повышения цели захвата;
* появления препятствий;
* появления опасных препятствий;
* появления движущихся объектов;
* усложнения геометрии игрового пространства.

### Вариант 1. Открытие файла

Можно открыть файл `index.html` двойным нажатием.

Открой PowerShell в папке проекта и выполни:

```powershell

```

При наличии Node.js можно выполнить:

```powershell
npx serve .
```

После запуска открой адрес, который появится в терминале.

## Возможные проблемы

### Игра отображается без оформления

Проверь, что рядом с `index.html` находится файл:

```text
style.css
```

И что в HTML указан правильный путь:

```html
<link rel="stylesheet" href="style.css">
```

### Кнопки не работают

Проверь наличие файла:

```text
script.js
```

И правильное подключение перед закрывающим тегом `body`:

```html
<script src="script.js"></script>
```

### Не отображаются изображения

Проверь:

* загружен ли каталог `objects`;
* сохранена ли структура вложенных папок;
* совпадает ли регистр букв;
* совпадают ли расширения файлов;
* нет ли лишнего двойного расширения;
* отсутствуют ли пробелы или кириллица в путях;
* доступны ли файлы через GitHub Pages.

### После обновления осталась старая версия

Попробуй выполнить принудительное обновление страницы:

```text
Ctrl + F5
```

Также можно очистить кеш браузера.
