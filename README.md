# JezzBall

JezzBall — адаптивная браузерная игра на HTML, CSS и JavaScript. Игрок проводит линии, захватывает безопасные области поля и проходит уровни с постепенно растущей сложностью.

## Что есть в проекте

- 100 уровней с разной скоростью шаров, целями и препятствиями.
- Главы, магазин, бустеры, скины, сундуки и достижения.
- Сохранение прогресса и поддержка локального режима.
- Интеграция с SDK Яндекс Игр: загрузка, реклама, покупки и сохранения.
- Адаптивный интерфейс для компьютера и мобильных экранов.

## Структура

```text
index.html      основной экран игры
style.css       стили интерфейса и адаптивность
script.js       игровая логика, уровни, магазин и SDK
objects/        фоны и игровые изображения
```

## Запуск

Проект не требует сборки. Для локальной проверки откройте `index.html` через локальный сервер, например через Live Server в VS Code.

## Проверка перед публикацией

```bash
node --check script.js
```

Перед загрузкой на Яндекс Игры стоит проверить запуск, адаптивность, магазин, рекламу, покупки и сохранение прогресса.
