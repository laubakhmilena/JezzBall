# Тесты

Здесь лежат автоматические проверки игры и их конфигурация.

Файлы `.mjs` — обычные JavaScript-модули для Node.js. Они нужны тестовой инфраструктуре и не входят в игровую сборку. Файлы `.spec.js` — браузерные сценарии Playwright, а `serve.mjs` — локальный сервер для проверки игры.

Для запуска после установки зависимостей:

```powershell
cd .\Тесты
pnpm install
pnpm test
```

Зависимости в текущей чистой папке не хранятся; папка `node_modules` удалена, чтобы не засорять проект и не попадать в релиз.
