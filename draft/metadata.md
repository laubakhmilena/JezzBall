# Данные для черновика JezzBall

## Технические поля

- Название: JezzBall
- Версия: 1.0.0
- Язык игры: русский
- Поддерживаемые платформы: Десктоп, Мобильные
- Ориентация: Любая — локально проверены десктопный альбомный режим, мобильный портретный и мобильный альбомный режимы.
- Возраст: 0+
- Категории: Головоломки, Аркады

## Фактическое содержание

Игрок проводит линии по игровому полю, делит свободное пространство, избегает движущихся шаров и достигает целевого процента захвата. В игре есть главы, уровни, бусты, очки, штрафы, победа, поражение и перезапуск.

## Проверка платформ

Размеры и действия для материалов проверены локально через HTTP-сервер. Проверка через авторизованный аккаунт, Яндекс Консоль, Game Ready debug panel и физические устройства остаётся `PENDING`.
