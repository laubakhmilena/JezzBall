# Комментарий разработчика

Игра запускается без сторонней регистрации. В локальном режиме прогресс и настройки сохраняются в `localStorage`; при доступном SDK Яндекс Игр код использует Player data для облачного сохранения и оставляет локальный fallback при недоступности платформы.

Реклама и покупки обращаются только через API SDK Яндекс Игр, если соответствующие методы доступны. Реальные каталог товаров, рекламные callbacks, облачная запись и debug panel не проверялись без доступа к Консоли, поэтому эти пункты имеют статус `PENDING`.
