# JezzBall — структура репозитория

## Игра

- [index.html](index.html) — страница игры.
- [script.js](script.js) — игровая логика.
- [style.css](style.css) — оформление.
- [load-sdk.js](load-sdk.js) — загрузчик SDK.
- [objects/](objects/) — игровые изображения и ресурсы.

Для запуска из корня репозитория: `python -m http.server 8000`, затем `http://localhost:8000`.

## Релиз и материалы

- [Релиз/](Релиз/) — готовый ZIP-архив игры.
- [assets/icons/](assets/icons/) — иконки и обложки.
- [assets/screenshots/](assets/screenshots/) — скриншоты.
- [assets/videos/](assets/videos/) — видео.
- [draft/](draft/) — метаданные, ключевые слова, комментарий разработчика и описания материалов.

## Тесты и QA

- [Тесты/](Тесты/README.md) — автоматические проверки и их конфигурация.
- [QA/](QA/README.md) — исторические отчёты, доказательства и тестовые копии.

Файлы `.mjs` и `.spec.js` нужны для проверок и не входят в игровую сборку. Папка `node_modules` не хранится в репозитории; зависимости тестов устанавливаются отдельно.
