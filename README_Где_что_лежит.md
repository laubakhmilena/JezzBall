# JezzBall — структура папки

## Запуск игры

Игровая сборка находится прямо в корне папки:

- `index.html` — страница игры;
- `script.js` — игровая логика;
- `style.css` — оформление;
- `load-sdk.js` — загрузчик SDK;
- `objects/` — обязательные изображения, звуки и прочие ресурсы игры.

Открывать для запуска нужно `index.html`. Папки `Тесты`, `QA_тестирование` и `Материалы_для_публикации` игре не нужны.

## Где лежат материалы

- `Релиз/` — готовые ZIP-архивы игры для загрузки;
- `Материалы_для_публикации/Иконки/` — иконки;
- `Материалы_для_публикации/Обложки/` — обложки без скруглённых внешних углов;
- `Материалы_для_публикации/Скриншоты/` — снимки игры для карточки;
- `Материалы_для_публикации/Видео/` — короткие записи игры;
- `Материалы_для_публикации/Тексты/` — ключевые слова, метаданные и чек-лист;
- `Материалы_для_публикации/Исходники_иконок/` — исходные варианты иконок.

## Тесты и QA

- `Тесты/` — автоматические тесты и их конфигурация;
- `QA_тестирование/` — отчёты, результаты аудита, доказательства и резервные копии.

Файлы `.mjs` — это JavaScript-модули Node.js для тестов и вспомогательных QA-скриптов. Это не отдельные игровые файлы и не мусор: игра их не загружает.

`node_modules` намеренно отсутствует в чистой папке. Он нужен только для локального запуска тестов и не должен попадать в релиз.
